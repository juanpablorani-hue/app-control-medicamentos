# MediRecord - Control de Medicamentos

MediRecord es una aplicación que ayuda a las personas a organizar sus medicamentos y recordar cuándo deben tomarlos.
Permite registrar información como el nombre del medicamento, la dosis y los horarios de toma para llevar un mejor control.

## Funciones que tendrá mi app

1. **Registro de medicamentos:** permitirá guardar el nombre del medicamento, la dosis indicada y las observaciones.
2. **Organización de horarios:** permitirá registrar las horas en las que se debe tomar cada medicamento.
3. **Control de tratamientos:** permitirá registrar las fechas de inicio y finalización para llevar un seguimiento organizado de los medicamentos.
